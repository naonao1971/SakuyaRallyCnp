# CNP 11体の画像

ゲーム内で回収する CNP 11体の絵。ファイル名は `index.html` の `CNP` 配列の
`id` に対応する。

| 項目 | 仕様 |
| --- | --- |
| 形式 | PNG（**背景透過必須**） |
| サイズ | 256×256（正方形） |
| 余白 | キャラ周囲の透明余白は詰めてある |

同じ画像を姉妹作の
[咲耶スクランブル](https://github.com/naonao1971/SakuyaScramble) でも使って
いる。差し替えるときは両方を揃えること。

ファイルが無いスロットは `index.html` の `drawCharPlaceholder()` が描く色付き
シルエット（「?」入り）で代替される。画像が1枚も無くても、回収・当たり判定・
レーダーはすべて動く。
